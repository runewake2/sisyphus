# 0.0.75

- Date: 2026-10-11
- Bookmark: samw/ai/ux-fixes
- Components: cli

## Summary

On a terminal, `sisyphus list` shortens the title column so that each row fits the width of the
terminal.

## Changes

- When stdout is a terminal, `list` makes the title column narrower, down to 10 characters, so that
  the table fits, and ends shortened titles with `…`. When stdout is not a terminal, and with the new
  flag `--wide`, titles are not shortened. `--json` does not change.
- `writeTableWithin` is `writeTable` with a maximum width for one column; `writeTable` calls it with
  no maximum.
- New direct dependency `golang.org/x/term` v0.45.0, for the terminal width on every platform. It is
  the newest version that keeps the minimum Go version at 1.25; v0.47.0 needs Go 1.26.
- [[sisyphus-list]] describes it. Tests cover a 70-column terminal, `--wide`, and output that is not a
  terminal.

None.

## Notes

When the other columns alone are wider than the terminal, the table stays wider than the terminal,
because the title column does not get narrower than 10 characters.
