## Summary

`sisyphus depends-on <name> <blocking-issue> --clear` warns when the issue does not depend on
`<blocking-issue>`, instead of reporting a change that did not happen.

## Changes

- When `--clear` names a dependency that the issue does not have, the command warns, names the
  dependencies that the issue has, and does not write the file. Before, it wrote the file and
  printed its path, so a typo looked like a removed dependency.
- [[sisyphus-depends-on]] describes the warning.
