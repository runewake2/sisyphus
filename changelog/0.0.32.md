## Summary

sisyphus-mcp passes free text that starts with `-` to sisyphus as text, not as a flag.

## Changes

- Every tool of sisyphus-mcp puts its positional arguments after `--`, and passes each flag as one
  `--flag=value` argument. Before, `sisyphus_edit` failed for every Markdown list (`- [ ] ...`),
  and `sisyphus_search` and `sisyphus_slug` failed for text that starts with `-`.
- A new test in `cmd/sisyphus-mcp` covers text that starts with `-` for `sisyphus_new`,
  `sisyphus_edit`, `sisyphus_search`, and `sisyphus_slug`.
- [[sisyphus-edit]] tells CLI users to put `--` before text that starts with `-`.
