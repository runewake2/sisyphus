# 0.0.85

- Date: 2026-10-11
- Bookmark: samw/ai/ux-fixes
- Components: sisyphus-mcp

## Summary

The `bookmark` and `workspace` arguments of the MCP tools no longer name only jj. They use the words
of the CLI flags, so an agent in a git repo knows that the arguments are for it too.

## Changes

- `bookmark` of `sisyphus_new` and `sisyphus_update` is "the jj bookmark or git branch of the work".
  `workspace` is "the jj workspace or git worktree where local work on the issue happens".
- A test fails when a tool or argument description names jj without git
  ([[0020-do-not-assume-jj]]).
