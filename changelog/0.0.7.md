- Date: 2026-10-07
- Bookmark: samw/ai/issue-dependencies
- Components: cli, schema

## Summary

Add explicit depends-on/blocks relationships between issues.

## Changes

- Issues can hold a `depends-on` list of quoted wikilinks: other issues that must close before this
  one can start.
- `sisyphus new --depends-on <issue>` sets one at creation.
- `sisyphus depends-on <name> <blocking-issue>` adds a dependency; `--clear` with a blocking issue
  removes just that one; `--clear` alone removes all of them.
- Adding a dependency that does not exist, is the issue itself, or would form a cycle (direct or
  transitive) is rejected with a clear error.
- Closing an issue warns if other open or in-progress issues still depend on it.
- `sisyphus list --blocked` and `sisyphus search --blocked` filter to issues with a dependency that
  is not yet closed.
