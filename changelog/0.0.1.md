- Date: 2026-10-07
- Bookmark: samw/ai/show-command
- Components: cli

## Summary

Add `sisyphus show` to print one issue's key fields and body.

## Changes

- `sisyphus show <name>` prints `title`, `state`, `priority`, `effort`, `tags`, `owner`, `approver`,
  `bookmark`, and `parent`, then the body. It accepts every reference form `update` and `parent`
  already accept: a name, `[[name]]`, `#name`, or a path.
- `--json` prints the same fields, plus `resolution`, `created`, `closed`, `workspaces`,
  `agent-session`, and `deferred-from`, as a JSON object with the body as a string.
