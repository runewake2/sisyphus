# 0.0.19

- Date: 2026-10-08
- Bookmark: samw/ai/index-issues-once
- Components: cli

## Summary

Each command reads the state directories once and parses each issue file at most once. Commands
that follow parent and depends-on links are now hundreds of times faster on large repos.

## Changes

- New `issueIndex` (`cmd/sisyphus/index.go`). A command builds it once. It answers a lookup by full
  name or by a shorter end of a name from two maps, and it parses each issue file on first use. It
  is not kept between commands, so each command sees the edits of other sessions.
- Lookups, full names of references, sub-issues, dependents, the cycle check, `list`, `search`,
  `show`, and `graph` use the index. Name resolution does not change.
- `sisyphus slug` reads the repo once, not once for each candidate name.
- A test runs each command and fails if it reads a state directory or an issue file twice.
- `cmd/sisyphus/bench_test.go` benchmarks four commands against 3000 generated issues.
