## Summary

`sisyphus update --add-tags` and `--remove-tags` add or remove single tags and keep the others.

## Changes

- New flags `update --add-tags` and `update --remove-tags`, comma-separated. Added tags go after the
  existing tags; a tag that is already there is not added again. Removing a tag that is not there is
  not an error. Both flags can be used together, but not with `--tags`.
- An added tag follows the same rule as `--tags`: it cannot contain a space.
- `sisyphus_update` has `addTags` and `removeTags` arguments.
- [[sisyphus-update]] lists the flags.
