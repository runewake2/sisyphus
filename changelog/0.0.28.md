## Summary

`sisyphus graph` draws the work path of `<name>` with heavy lines, from the issues to start now
to `<name>`, and names those issues in the legend.

## Changes

- The work path is what `<name>` waits on, all the way down: dependencies and sub-issues that are
  not closed. Its arrows have heavy lines (`━━►`, `┅┅►`), and the legend gains `━━► work path`.
- A legend line `start now: …` names the available issues where the work path ends.
- With color, the work path and the borders of the start-now issues are bold magenta.
- Lines mix light and heavy weights with the right Unicode characters. The join where an arrow
  leaves a heavy box is now `┠`, not `┝`.
- [[sisyphus-graph]] has a Work path section and new examples.
