## Summary

The README is now for people who use sisyphus in their own repo: what it is, install, a first
session with real output, the main commands, completion, Obsidian, and MCP. Its links are Markdown
links that work on GitHub, and a test checks them.

## Changes

- A new description of sisyphus, and an install section with only `go install` and `init`.
- A first session (`new`, `start`, `list`, `close`, `show`), recorded with sisyphus 0.0.82 in a new
  git repo.
- A table of the main commands, with links to [[commands]] and [[issue-format]].
- The MCP section gives the install and the Claude Code command, and links to [[sisyphus-mcp]] for
  the rest, in place of one long line with every tool name.
- The contributor workflow of this repo is one line under Contributing, not part of the usage.
- Every link is a Markdown link. A test checks that the README has no wikilink outside code, and
  that each relative link names a file.
