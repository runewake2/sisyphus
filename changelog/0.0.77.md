- Date: 2026-10-11
- Bookmark: samw/ai/ux-fixes
- Components: cli

## Summary

sisyphus no longer assumes jj: the bookmark warning comes only in a jj repo, the template describes
`bookmark` and `workspaces` for git too, and a template without them keeps working.

## Changes

- `new` and `update` warn about an in-progress issue without a bookmark only when the repo root has a
  `.jj` directory.
- The embedded template and the help of `--bookmark` and `--workspace` describe them as a jj bookmark
  or git branch, and jj workspaces or git worktrees.
- `document.set` adds a missing frontmatter field only to set a value, so that clearing a field that a
  template does not have adds nothing.
- [[sisyphus-new]] and [[sisyphus-update]] say when the warning comes. Tests cover a repo without jj,
  a repo with jj, and a template without `bookmark` and `workspaces` through `new`, `start`, `update`,
  and `lint`.
