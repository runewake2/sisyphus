# 0.0.31

- Date: 2026-10-09
- Bookmark: samw/ai/edit-issue-sections
- Components: cli, mcp

## Summary

Add `sisyphus edit`, which replaces or appends to one section of an issue's body, and the MCP
tool `sisyphus_edit`.

## Changes

- New `sisyphus edit <name> <section> <text>` replaces the text of one section, for example
  `Resolution`. `--append` adds the text after the current text, but replaces a section that holds
  only the template placeholder. `-` as `<text>` reads standard input.
- An unknown section is an error that lists the sections of the issue. The title is not a section.
- `sisyphus update <name> closed` warns when the `Resolution` section still holds the template
  placeholder, and names the `edit` command that completes it.
- New MCP tool `sisyphus_edit`.
- sisyphus-mcp returns the warnings of a command after its output. Before, it dropped them when the
  command did not fail.
- New [[sisyphus-edit]]. [[commands]], [[sisyphus-update]], [[sisyphus-mcp]], the README, and
  [[CONTRIBUTING]] list the command.
