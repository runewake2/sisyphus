# 0.0.98

- Date: 2026-10-11
- Bookmark: samw/ai/ux-fixes
- Components: cli, sisyphus-mcp, docs

## Summary

`sisyphus search` matches an issue that has all words of the query, in any order. Before, the query
had to be one exact phrase, so `docs site theme update` did not find "Update the docs site theme".

## Changes

- The query is split into words. An issue matches when its title and body have every word, without
  regard to case.
- Words in double quotes match as one exact phrase, for example `'"session cache" login'`.
- The matched lines of [[0.0.94]] are the lines that have a word or phrase of the query.
- The help of `search`, the `query` and the description of `sisyphus_search`, and
  [[sisyphus-search]] tell that the words can be in any order, and how to search for a phrase.
- Tests cover word order, words in the title and the body, and exact phrases.
