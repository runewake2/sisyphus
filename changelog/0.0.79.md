# 0.0.79

- Date: 2026-10-11
- Bookmark: samw/ai/ux-fixes
- Components: cli

## Summary

The help of every command has examples, the root help groups the commands by purpose and tells what
sisyphus is, and every command line of the root help fits in 80 characters.

## Changes

- Every command has 2-4 examples in its `--help`. The examples are in `help.go`, and a test checks
  that each line is also on the docs page of the command. New example lines on [[sisyphus-new]],
  [[sisyphus-start]], [[sisyphus-close]], [[sisyphus-abandon]], and [[sisyphus-slug]].
- The root help has a description of sisyphus and the first two commands to run, and groups the
  commands: create and change issues, read and find issues, relate issues, check names and links,
  and set up.
- Shorter descriptions for `new`, `update`, `parent`, `remote`, `depends-on`, `edit`, `slug`, `list`,
  `resolve`, `links`, `lint`, `init`, `open`, `abandon`, `completion`, and `-C`. `parent` and
  `remote` keep the longer text in their own help. The `help` command has a description in the style
  of the other commands.
- A test checks the groups and the length of the command lines of the root help.
