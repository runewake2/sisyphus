- Date: 2026-10-07
- Bookmark: samw/ai/editable-metadata
- Components: cli

## Summary

Let `sisyphus update` change `priority`, `effort`, and `tags` on an existing issue.

## Changes

- `sisyphus update <name> <state> --priority <p> --effort <e> --tags <t>` changes those fields,
  validated the same way `sisyphus new` validates them. Omitting a flag leaves its field untouched.
- Extracted `formatTags`, shared by `new` and `update`, instead of duplicating the tag-parsing logic.
