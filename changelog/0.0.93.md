## Summary

New page [[agents]] tells how to let AI agents use sisyphus in a repo, with instructions to paste
into `AGENTS.md` or `CLAUDE.md`.

## Changes

- [[agents]] has the setup (shell or MCP, and `SISYPHUS_OWNER` for each agent), a long and a short
  block of instructions for a shell, a block for MCP, how several agents work together in one
  working copy, in several workspaces, and on several machines, and what sisyphus does not do for
  agents.
- The instructions tell agents never to run `sisyphus edit <name>` without a section, because it
  opens an editor and waits.
- A test checks that each command and flag on the page exists, because agents copy the text.
- The README, [[sisyphus-mcp]], and [[commands]] link to the page.
