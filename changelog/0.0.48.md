## Summary

sisyphus keeps the line endings of an issue file when it writes it, so that one field change is a
one-line diff also in a file with CRLF line endings.

## Changes

- `parseDocument` notes whether the first line ends with CRLF, and `render` writes every line with
  that line ending. Before, every write changed CRLF to LF on every line.
- A new issue takes the line endings of `issues/TEMPLATE.md`.
- Tests cover an update of a CRLF file and a new issue from a CRLF template.
