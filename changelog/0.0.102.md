# 0.0.102

- Date: 2026-10-11
- Bookmark: samw/ai/ux-fixes
- Components: sisyphus-mcp, docs

## Summary

The sisyphus-mcp tools have titles and annotations, and JSON results come back as structured
content too. A client can now see which tools only read, and approve them without a prompt.

## Changes

- Each tool has a `title` and annotations: `readOnlyHint` for the 8 tools that only read,
  `destructiveHint` for the tools that can replace or remove, `idempotentHint`, and
  `openWorldHint: false`.
- A result whose output is JSON also has it as `structuredContent`. A JSON array is wrapped as
  `{"results": [...]}`. Only stdout is parsed, so warnings stay in the text.
- The tools have no `outputSchema`: a tool that returns text on request could not give structured
  content for the text, and the protocol requires it when a schema is given. This differs from the
  acceptance criterion of the issue.
- Tests check the titles, the read-only set, and the structured content of `show`, `list`,
  `lint`, and of a text and a path result.
- [[sisyphus-mcp]] lists the annotations and describes the structured content.
