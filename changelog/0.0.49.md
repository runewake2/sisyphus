## Summary

`sisyphus edit` refuses text with a heading that would split the section.

## Changes

- `edit` (and `edit --append`) fails when the text has a heading, outside code blocks, at the level
  of the section or above. The error names the heading, and the file does not change. Before, text
  with `## Notes` made a second Notes section, and a later `edit Notes` changed that one instead of
  the real one.
- A deeper heading, for example `###` in a `##` section, and a heading inside a code block are
  still allowed.
- [[sisyphus-edit]] states the rule.
