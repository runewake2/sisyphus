- Date: 2026-10-11
- Bookmark: samw/ai/ux-fixes
- Components: sisyphus-mcp, docs

## Summary

sisyphus-mcp has the tools `sisyphus_start`, `sisyphus_close`, and `sisyphus_abandon`, with the
names of the CLI commands. Before, an agent had to know that it must use `sisyphus_update` with
`state` and `resolution` for them.

## Changes

- `sisyphus_start` takes `name`, `owner`, `bookmark`, `workspace`, `take`, and `json`. It refuses
  an issue that another owner or workspace has, as [[sisyphus-start]] does.
- `sisyphus_close` and `sisyphus_abandon` take `name`, `message`, and `json`. `message` is required
  and must not be empty, so that the Resolution section tells what happened.
- [[sisyphus-mcp]] lists the tools, and its example session uses them and shows a refused start.
