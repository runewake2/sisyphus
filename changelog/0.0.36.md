## Summary

The text tables of `sisyphus list` and `sisyphus links` align their columns when a cell has wide
characters, for example CJK text.

## Changes

- `writeTable` pads each column by terminal display width (`runewidth.StringWidth`), not by the
  number of runes. A CJK letter takes two columns, so before, the columns after a CJK title moved to
  the left on that row. The graph drawing already measured width this way.
- A test checks that the state column of each `list` row starts at the same display column as its
  header.
