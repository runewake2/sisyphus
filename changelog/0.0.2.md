## Summary

Move issue files through git when the repo has a `.git` directory, instead of a plain rename.

## Changes

- `saveIssue` now moves an issue file with `git mv` when `root/.git` exists, so the move lands in
  the git index immediately instead of as an untracked delete-and-add. jj-only repos are unchanged:
  jj detects a rename from content when it next snapshots the working copy.
