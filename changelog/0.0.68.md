## Summary

New global flag `-C <directory>` runs sisyphus on another repo without `cd`, as `git -C` does.

## Changes

- `-C` (`--directory`) works with every command, before or after the command name. The search for
  the repo root starts there instead of in the current directory. A relative path is taken from the
  current directory; a path that is not a directory is an error.
- `init` writes into `-C`, and a relative `--dir` is taken from `-C`.
- `findRoot` is split into `findRootFrom`, which searches up from given directories.
- [[commands#How sisyphus finds the repo]] and [[sisyphus-init]] describe the flag. Tests cover an
  absolute path, a relative path, a file, and `init`.
