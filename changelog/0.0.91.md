# 0.0.91

- Date: 2026-10-11
- Bookmark: samw/ai/ux-fixes
- Components: sisyphus-mcp, docs

## Summary

sisyphus-mcp tells the agent when the `sisyphus` binary that it runs has another version. Before, a
tool that passed a flag that an old binary did not know gave only `unknown flag`, with no hint about
the cause.

## Changes

- sisyphus-mcp runs `sisyphus --version` once for each binary that it finds. When the version is
  different from its own, it adds a line to every error result:
  `sisyphus-mcp 0.0.91 runs sisyphus 0.0.80 from /usr/local/bin/sisyphus. Install the same version of both, ...`,
  and writes the line to its log.
- A test runs the tools against a fake `sisyphus` with another version.
- The troubleshooting table of [[sisyphus-mcp]] has a row for it.
