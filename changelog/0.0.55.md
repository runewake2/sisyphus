## Summary

Tags are stored in lowercase, and filters and tag changes compare them without regard to case.

## Changes

- `new --tags`, `update --tags`, and `update --add-tags` write tags in lowercase.
- `list --tags`, `search --tags`, `--add-tags`, and `--remove-tags` compare tags without regard to
  case. Before, `list --tags bug` did not find an issue with the tag `Bug`.
- `updateIssue` ran the `--add-tags`/`--remove-tags` code twice, a mistake from [[0.0.42]]. The
  result was the same, because both steps are idempotent; the second copy is gone.
- [[sisyphus-new]] and [[sisyphus-update]] state the rule.
