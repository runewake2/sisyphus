## Summary

`sisyphus new --depends-on` takes more than one issue.

## Changes

- `new --depends-on a,b` and `new --depends-on a --depends-on b` add each issue to `depends-on`, in
  order and without duplicates. Each issue must exist and cannot create a cycle; the error names the
  issue that fails, and no file is written. Before, `--depends-on a,b` looked for one issue named
  `a,b`.
- `dependsOn` of `sisyphus_new` takes a comma-separated list.
- [[sisyphus-new]] describes the flag.
