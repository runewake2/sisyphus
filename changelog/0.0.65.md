# 0.0.65

- Date: 2026-10-11
- Bookmark: samw/ai/perf-fixes
- Components: cli

## Summary

The link maps of [[0.0.58]] are built only when a command looks up many links, so `resolve` and
`links` on a small document are as fast as before 0.0.58 again.

## Changes

- 0.0.58 built a map of every file and every path suffix for each command. For `lint`, with about
  200,000 links at 20,000 issues, that is far cheaper than a scan per link. But for `resolve` and for
  `links` on a document with a few links, building the maps cost more than the scans: at 20,000 issues,
  `resolve` took 66 ms instead of 39 ms.
- `matchTarget` now scans the list for the first 64 lookups of a command, and builds the maps on the
  next one. Both ways give the same result; a new test compares them on exact, suffix, case,
  non-Markdown, and missing targets, with and without `--all`.
- On generated repos, `links --json`, `resolve --all`, and `lint --json` are the same as before.

| 20,000 generated issues | 0.0.57 | 0.0.64 | 0.0.65 |
|---|---|---|---|
| `resolve [[name]]` | 40 ms | 66 ms | 40 ms |
| `links <doc with 20 links>` | 45 ms | 66 ms | 46 ms |
| `lint` | 39,021 ms | 1,269 ms | 1,264 ms |
