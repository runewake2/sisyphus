## Summary

sisyphus reads an issue file that starts with a UTF-8 byte order mark, and keeps the mark when it
writes the file.

## Changes

- `parseDocument` removes a leading UTF-8 BOM before it looks for the frontmatter, and `render`
  writes the BOM back. Before, every command failed with "The file does not start with YAML
  frontmatter", and `list` and `lint` called the file unreadable.
- `splitLines` removes a leading BOM, so that the link checks also find a heading on the first line
  of such a file.
- Tests cover `show`, `update`, and `lint` for an issue with a BOM, and a link to a heading in a
  document with a BOM.
