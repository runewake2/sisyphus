## Summary

`sisyphus show` leaves out empty fields and the sections that hold only template text, so that a
new issue shows what it is, not what to write. `show --all` prints everything.

## Changes

- The text output of `show` leaves out the fields that are empty, `[]`, or `{}`, except `title`,
  `state`, `priority`, `effort`, and `created`. The values start in the same column as before.
- It leaves out each `##` section whose text is only the template placeholders: `<...>` paragraphs
  and items such as `- [ ] <Condition>`. A section with any real text shows in full.
- `show --all` prints every field and section, as before. `show --json` does not change.
- [[sisyphus-show]] describes the default and `--all`. Tests cover hidden and kept fields and
  sections.
