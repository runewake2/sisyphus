# 0.0.84

- Date: 2026-10-11
- Bookmark: samw/ai/ux-fixes
- Components: cli, docs

## Summary

`sisyphus open` is gone: `sisyphus edit <name>` opens an issue in your editor. `open` sounded like
it reopens an issue, because `open` is also a state.

## Changes

- `edit` takes `<name>` alone, to open the file in `$VISUAL` or `$EDITOR` and check it after, or
  `<name> <section> <text>`, as before. Two arguments, and `--append` or `--json` with only a name,
  are errors that tell the two forms.
- The `open` command, its completion, and its group entry are removed. Its tests now run `edit`.
- [[sisyphus-edit]] has the editor form; `docs/sisyphus-open.md` is removed. [[commands]], the
  README, [[issue-format]], [[sisyphus-mcp]], and [[0.0.76]] refer to `edit`.
- `sisyphus_edit` of [[sisyphus-mcp]] does not change: it still needs a section and text.
