## Summary

The error for an issue name that does not exist suggests up to 3 existing issues, with their
titles. Models guess names, and before, the error gave them nothing to correct the call with.

## Changes

- `No issue named '<name>' ...` adds `Did you mean: <name> (<title>), ...?` for the issues whose
  names and titles share the most words with the name. A near word counts too, for example
  `convention` and `conventions`, or `docs` and `doc`. Filler words such as `the` do not count.
- Issues that are not closed come first, and a closed issue says `closed:` before its title.
- Every command that takes an issue name gets the suggestions, and so does every MCP tool.
- [[commands#Naming an issue]] describes them.
