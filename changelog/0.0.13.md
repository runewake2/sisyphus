# 0.0.13

- Date: 2026-10-07
- Components: cli, mcp

## Summary

`sisyphus --version` now prints the version the binary was compiled from, in any directory.

## Changes

- The module root now has a small `sisyphus` package that embeds `VERSION` at compile time
  (`sisyphus.Version()`). Before, `--version` read the `VERSION` file of whatever repo it ran in:
  outside a sisyphus repo the flag did not exist, and inside another project it printed that
  project's version.
- `sisyphus-mcp` reports the same compiled version in its MCP `serverInfo`, instead of a
  hardcoded `0.0.1`.
