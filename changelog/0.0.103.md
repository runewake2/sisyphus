## Summary

New page [[output]] describes the rules for stdout, stderr, and exit codes, and the shape of each
JSON output, so that scripts and agents can rely on them.

## Changes

- [[output]] has: what goes to stdout and to stderr, the form of warnings and errors, the exit
  codes (with `lint` and `links` as the special cases), a table of the commands with `--json`, and
  the fields of each JSON shape.
- It states the rule for changes: fields are only added, and a change that can break a script is
  marked **Changed:** in the changelog and has a decision record.
- A test checks that the page names every field of every JSON type, so that a new field cannot be
  left out.
- [[commands#Output and exit codes]] lists every command with `--json` and links to the page.
