## Summary

`sisyphus new` and `sisyphus update --tags` reject a tag that contains a space.

## Changes

- A tag with whitespace inside it, for example `needs review`, is an error in `new --tags` and
  `update --tags`. The error suggests the kebab-case form, `needs-review`. Before, such a tag was
  written to the frontmatter, where it is not a valid Obsidian tag.
- Spaces around a tag are still trimmed: `"bug, ui"` stays valid.
- [[sisyphus-new]] and [[sisyphus-update]] state the rule.

## Decisions

None.

Existing issues with such tags are not changed. [[lint-issues-command]] can report them.
