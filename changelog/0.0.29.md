## Summary

Record the results of the spike that tested local Ollama models as sisyphus task managers, and the
follow-up work that the spike found.

## Changes

- [[ollama-local-models]] (`design/ollama-local-models.md`): the report. It compares qwen3:4b,
  qwen3:8b, qwen3.5:9b, ministral-3:8b, qwen3:14b, and Claude Opus 5.5 on 14 tasks, and recommends
  qwen3.5:9b with thinking on (28 of 28 runs passed, 3.3 s for each task, 5.8 GB of VRAM).
- `design/ollama-local-models/harness/`: the benchmark harness and the run scripts, so that the
  results can be made again after changes to `sisyphus-mcp`.
- `design/ollama-local-models/results/` and `notes/`: the raw results and one analysis for each
  model.
