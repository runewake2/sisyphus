## Summary

`sisyphus graph --full` draws each issue that only `--full` adds, linked to `<name>` but not below
it or on its path above it, in a dashed box.

## Changes

- Such an issue has a light dashed box (`┌╌┐`), or a heavy dashed box (`┏╍┓`) if it is available.
  The legend lists each dashed style that the drawing uses.
- In `--json`, such a node has `indirect: true`.
- In `--mermaid`, the class `indirect` gives such a node a dashed border.
- The graph help, the `sisyphus_graph` MCP description, and [[sisyphus-graph]] describe the
  dashed boxes.
