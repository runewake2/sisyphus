## Summary

`sisyphus update <name> open --reopen` reopens an issue whose close was a mistake.

## Changes

- New flag `update --reopen`. With the state `open` or `in-progress`, it moves a closed issue
  back, clears `resolution` and `closed`, and adds a dated line to `Notes` with the old resolution
  and closed date. It fails for an issue that is not closed.
- The error for a reopen without the flag says that a closed issue stays closed, and names `--reopen`
  for a close that was a mistake.
- `sisyphus_update` has a `reopen` argument.
- [[sisyphus-update]] and [[CONTRIBUTING#Issue lifecycle]] describe when to use it.
