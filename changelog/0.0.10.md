# 0.0.10

- Date: 2026-10-07
- Bookmark: samw/ai/narrow-init
- Components: cli, schema

## Summary

Narrow `sisyphus init` to set up `issues/` only, and replace the `agent-session` field with a
generic `metadata` field.

## Changes

- `sisyphus init` now writes only `issues/TEMPLATE.md` and the `open`/`in-progress`/`closed`
  directories. Removed `AGENTS.md.tmpl`, `CONTRIBUTING.md.tmpl`, `CHANGELOG.md.tmpl`,
  `VERSION.tmpl`, `changelog/0.0.0.md.tmpl`, `design/decisions/.gitkeep.tmpl`, and the two
  `.github/workflows/*.yml.tmpl` from the kit, along with the now-unused `--project` and
  `--bookmark-prefix` flags. This repo's own copies of those files stay, maintained directly.
- Replaced `agent-session` with `metadata`, a generic `{key: value, ...}` field. `sisyphus new
  --metadata` and `sisyphus update --metadata` (repeatable `key=value`, merged into the existing
  map) let an agent record arbitrary notes, such as a session id, without it being a named,
  always-present part of the schema or auto-cleared on every state change.
- Migrated every existing issue file's `agent-session:` to `metadata: {}`.
