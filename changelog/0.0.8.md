# 0.0.8

- Date: 2026-10-07
- Components: cli

## Summary

Default a closed issue's resolution to `completed` instead of requiring `--resolution`.

## Changes

- `sisyphus new --state closed` and `sisyphus update <name> closed` no longer require
  `--resolution`: it defaults to `completed`. An explicit `--resolution abandoned` still works, and
  still wins over the default.
- `--resolution` on a state other than `closed` is still rejected.
