# 0.0.14

- Date: 2026-10-07
- Components: cli

## Summary

Make sisyphus itself independent of any particular repo or issue.

## Changes

- The `issues/TEMPLATE.md` that `sisyphus init` writes no longer carries this repo's conventions:
  the `bookmark` comment no longer names the `samw/ai/` bookmark prefix, and the examples
  (`fix-login-bug`, "Add retry backoff") are generic instead of real issue and workspace names.
- The invalid-name error suggests `fix-login-bug` instead of a real issue name.
- The tests build their temporary repos from the embedded template instead of this repo's
  `issues/TEMPLATE.md`, no longer read this repo's `VERSION`, and use neutral fixture names and
  people (`alice`, `bob`, `ai/work`). They now pass in a copy of the source with no `issues/`.
- `CONTRIBUTING.md` states the rule, so it is not broken again.
