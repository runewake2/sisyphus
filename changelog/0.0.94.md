# 0.0.94

- Date: 2026-10-11
- Bookmark: samw/ai/ux-fixes
- Components: cli, sisyphus-mcp, docs

## Summary

The JSON of `show` and `search` is much smaller, because agents read it into their context. A search
for `mcp` in this repo returned 45,673 bytes and now returns 13,284.

## Changes

- `show --json`, and the `--json` output of the commands that change an issue, leave out the
  sections that hold only template text. `show --json --all` keeps the body as it is in the file.
- `search` does not match template text, so a word of a placeholder no longer matches every issue.
- `search` with a query returns the matched lines with their sections (`matches` in JSON), at most
  5 for each issue, cut to 200 characters around the match. The text output shows the same lines.
  **Changed:** `content` is now returned only with `--section`, or with the new `--content`.
- `list` and `search` take `--limit`, and tell on stderr how many issues were left out.
- The MCP tools take `all` (`sisyphus_show`), `content` (`sisyphus_search`), and `limit`
  (`sisyphus_list`, `sisyphus_search`).
- [[sisyphus-show]], [[sisyphus-search]], and [[sisyphus-list]] describe the changes. The decision
  is [[0025-keep-json-small-for-agents]].
