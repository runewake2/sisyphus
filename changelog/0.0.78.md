## Summary

`sisyphus completion <shell>` prints a completion script for bash, zsh, fish, PowerShell, or
Nushell. The scripts complete commands, flags, issue names, states, sections, and flag values.

## Changes

- New `completion` command, with the cobra scripts for bash, zsh, fish, and PowerShell, and an
  external completer for Nushell that calls `sisyphus __complete`.
- Commands that take an issue complete its name, with its title. `start` offers open issues, `close`
  and `abandon` offer open and in-progress issues, and other commands offer all issues. `update`
  completes the new state, and `edit` the section headings of the issue.
- `--state`, `--priority`, `--effort`, `--resolution`, and `--color` complete their values; on `list`
  and `search`, each item of a comma-separated list. `--tags`, `--add-tags`, and `--remove-tags`
  complete the tags in use. `--parent`, `--depends-on`, and `--deferred-from` complete issue names.
  `-C` and `init --dir` complete directories.
- New page [[sisyphus-completion]], with install steps for each shell, a row in [[commands]], and a
  Shell completion section in the README.
- Tests cover issue names, states, sections, flag values, and the script of each shell. The scripts
  were also run in bash 5, zsh, fish, PowerShell 7.6, and Nushell 0.116.
