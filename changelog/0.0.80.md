- Date: 2026-10-11
- Bookmark: samw/ai/ux-fixes

## Summary

Every command page in `docs/` has the same sections: Usage, Flags, Behavior, Output, and Examples. A
test checks the sections and that every flag of a command is in the Flags table of its page.

## Changes

- New Flags tables on [[sisyphus-parent]], [[sisyphus-remote]], [[sisyphus-depends-on]],
  [[sisyphus-links]], [[sisyphus-show]], and [[sisyphus-slug]] (None). [[sisyphus-edit]] and
  [[sisyphus-lint]] have a Flags heading over their table. [[sisyphus-new]], [[sisyphus-update]],
  [[sisyphus-edit]], [[sisyphus-parent]], [[sisyphus-remote]], and [[sisyphus-depends-on]] list
  `--json`.
- "What it does", "Rules", "What it checks", "What it matches", and "How a link matches" are now
  Behavior. [[sisyphus-list]] and [[sisyphus-show]] have a Behavior section.
- [[sisyphus-graph]]: Options is now Flags, before Behavior; Color is a subsection of Behavior; the
  Mermaid example is in Output.
- [[commands]] groups the commands as the root help does.
- The checklist of [[CONTRIBUTING]] asks for these sections on a new command page.
