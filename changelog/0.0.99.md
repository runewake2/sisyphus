# 0.0.99

- Date: 2026-10-11
- Bookmark: samw/ai/ux-fixes
- Components: sisyphus-mcp, docs

## Summary

The sisyphus-mcp tools no longer have a `dir` argument by default. Small models filled the optional
`dir` with words of its description, and those calls failed. Two new flags of the server cover the
clients that need another directory.

## Changes

- Without flags, no tool has `dir`, and the tools act on the working directory of the server.
- `--dir <path>` sets that directory. `--allow-dir` gives every tool the `dir` argument again, with a
  description that tells the model to leave it out, and a line about it in the instructions.
- **Changed:** a client that gave `dir` in its calls must start the server with `--allow-dir`.
- Tests check that the default tools have no `dir`, that a call with `dir` is refused, and that the
  tools act on the directory of the server. The other tests run with `--allow-dir`.
- [[sisyphus-mcp]] describes the flags, and its troubleshooting table has rows for them. The
  decision is [[0026-hide-the-dir-argument-by-default]].
- `github.com/google/jsonschema-go` is now a direct dependency, to remove `dir` from the schemas.
