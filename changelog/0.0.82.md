- Date: 2026-10-11

## Summary

[[sisyphus-mcp]] now tells how to set up Claude Code and any other MCP client, how output, warnings,
and errors come back, and what to do when a call fails, with an example session.

## Changes

- Setup for Claude Code (local and project scope) and a generic JSON configuration, with the full
  paths and `PATH` that a client started from a desktop launcher needs.
- How the server picks the repo, and when to give `dir`.
- The tool table gives the default output of the commands that change an issue (the path, or JSON
  with `json: true`), and says which commands have no tool and why.
- Results: output, warnings after the output, errors with `isError`, and argument type errors. Lists
  are comma-separated strings.
- An example session, recorded from `sisyphus-mcp` 0.0.81 in a new git repo.
- A troubleshooting table. The README links to the page for all of this.
