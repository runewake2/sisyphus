## Summary

Finish the github-source-of-truth epic: a GitHub Action that turns a filed GitHub issue into a
sisyphus-issue PR, a GitHub Action that mirrors sisyphus issues to GitHub on push to `main`, and the
two small CLI pieces both of them need.

## Changes

- `sisyphus slug <text>`: prints a unique, valid issue name made from arbitrary text (for example a
  GitHub issue title), trimmed to 2-6 words and deduplicated with a numeric suffix.
- `sisyphus new --context <text>`: replaces the `## Context` section's placeholder with `text`,
  using a new `replaceSection` helper (`links.go`, alongside the existing `sectionIn`).
- `sisyphus show` (text and `--json`) now includes `remote` and `depends-on`, which it had been
  missing since those fields were added.
- `.github/workflows/issue-to-pr.yml` (added to the init kit): on a new GitHub issue, opens a PR
  that adds a matching sisyphus issue, pinned to it via `remote`, using `sisyphus slug` and
  `sisyphus new --context`.
- `.github/workflows/sync-to-github.yml` (added to the init kit): on push to `main`, creates or
  updates a GitHub issue for every sisyphus issue, using `sisyphus list`/`show`/`remote` plus `gh`.
- `CONTRIBUTING.md` (and the kit template) documents the one-way "sisyphus is always the source of
  truth" design in a new `### GitHub issues` subsection.
