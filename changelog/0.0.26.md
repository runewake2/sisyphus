# 0.0.26

- Date: 2026-10-08
- Bookmark: samw/ai/graph-directory-boxes
- Components: cli

## Summary

As an experiment, `sisyphus graph` colors `<name>` and the arrows attached to it bold bright cyan
on a terminal, and the rest of the drawing gray.

## Changes

- New `--color auto|always|never` flag. `auto`, the default, colors only on a terminal, and not
  when `NO_COLOR` is set or `TERM` is `dumb`.
- With color, `<name>`'s box and each arrow that leaves or enters it, with its arrowhead, are bold
  bright cyan. Everything else in the drawing is gray. The legend has no color.
- `--json`, `--mermaid`, and output that is not a terminal do not change.
- [[sisyphus-graph]] describes the flag and the colors.
