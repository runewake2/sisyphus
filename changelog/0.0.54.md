- Bookmark: samw/ai/tracker-fixes-2

## Summary

Every command finds an issue by name without regard to case, as wikilinks and `sisyphus resolve`
already did.

## Changes

- The issue index tries a name again in lowercase when it matches nothing. Valid issue names are
  lowercase, so this cannot make a name ambiguous. Before, `sisyphus resolve "[[META-TEST]]"` found
  `meta-test`, but `sisyphus show META-TEST` failed.
- Output and errors still use the real, lowercase name. A new issue name must still be lowercase.
- [[commands#Naming an issue]] states the rule.
