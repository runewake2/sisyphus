## Summary

`sisyphus list --ready` and `sisyphus search --ready` show the issues that can start now.

## Changes

- New flag `--ready` for `list` and `search`: issues that are not closed and have no `depends-on`
  issue and no sub-issue that is not closed. It is the rule that `sisyphus graph` uses for available
  issues. It cannot be used with `--blocked`.
- `sisyphus_list` and `sisyphus_search` have a `ready` argument.
- [[sisyphus-list]], [[sisyphus-search]], and the README describe the flag.
- A test checks that `list --ready` agrees with the available nodes of `graph --json --full`.
