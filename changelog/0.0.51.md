## Summary

`sisyphus new --deferred-from` warns when the value names no issue and is not a bookmark.

## Changes

- `new --deferred-from` with a value that has no `/` and names no issue, or with a wikilink to no
  issue, warns and names the value. The issue is still written, with the value as a wikilink.
  Before, a typo became a broken link with no message, and only `sisyphus lint` found it.
- [[sisyphus-new]] describes the warning.

## Decisions

None. A warning, not an error, because the value may name an issue that was removed on purpose.
