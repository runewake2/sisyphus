# 0.0.21

- Date: 2026-10-08
- Bookmark: samw/ai/graph-directory-boxes
- Components: cli, mcp

## Summary

`sisyphus graph` draws each issue subdirectory as a box around the issues below it, and each
issue box shows only its file name. Box line styles replace the emoji marks, and sisyphus draws the
graph itself instead of with mermaid-ascii.

## Changes

- Each directory of a drawn issue is a rounded box (`╭─╮`) with its name in the top border, nested
  as the directories nest. A box holds exactly the issues below its directory, and sibling boxes do
  not overlap.
- `<name>` has a double box (`╔═╗`), a leaf a heavy box (`┏━┓`), and other issues a light box. The
  legend shows the styles. The 📍 and 🍃 marks are gone from the drawing and from `--mermaid`.
- `--mermaid` output has one `subgraph` per directory, and `classDef` lines for the focus issue and
  the leaves.
- The terminal drawing comes from a new layout and renderer in `cmd/sisyphus/layout.go`,
  `render.go`, and `canvas.go`. `github.com/AlexanderGrooff/mermaid-ascii` is no longer a
  dependency, and `github.com/mattn/go-runewidth` is a direct one.
- The `graph` help, the `sisyphus_graph` MCP description, and [[sisyphus-graph]] describe the boxes.
- `--json` output does not change.
