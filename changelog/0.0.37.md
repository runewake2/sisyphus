## Summary

`sisyphus new` and `sisyphus update` fail when an open issue would get an owner or a bookmark,
instead of dropping or keeping the value without a message.

## Changes

- `update <name> open --owner <value>` (or `--bookmark`) fails, and the issue does not change.
  Before, it exited 0 and cleared the owner.
- `new --owner <value>` (or `--bookmark`) for an open issue fails too. Before, it wrote the owner.
- `--owner ""` with the state `open` still works.
- [[sisyphus-new]] and [[sisyphus-update]] state the rule.
