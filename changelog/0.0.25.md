- Date: 2026-10-08
- Bookmark: samw/ai/graph-directory-boxes
- Components: cli, mcp

## Summary

`sisyphus graph` shows the state of an issue on a second line below its name, so boxes and graphs
are narrower.

## Changes

- An issue box is four lines high, with the file name on the first inner line and the state, with
  no brackets, on the second. Arrows leave and enter on the line of the name.
- `--mermaid` labels and `--json` do not change.
- The graph help, the `sisyphus_graph` MCP description, and [[sisyphus-graph]] describe the second
  line, and the examples are drawn again.
