# 0.0.59

- Date: 2026-10-11
- Bookmark: samw/ai/perf-fixes
- Components: cli

## Summary

`sisyphus lint` finds parent cycles and dependency cycles in one pass each, and reports each cycle
once, as its issues in order.

## Changes

- Dependency cycles: one pass of Tarjan's strongly connected components over all `depends-on`
  links. Each group of issues that depend on each other is one problem, with a shortest cycle
  through it: `its dependencies form a cycle: a → b → c → a`. Before, `lint` started a new search
  from every dependency of every issue, so a long chain was quadratic, and each issue in a cycle got
  its own line.
- Parent cycles: one walk over the parent links, which finds each cycle once:
  `its parent chain is a cycle: a → b → a`.
- A dependency on the issue itself, and entries that name no issue, are still reported for each
  issue.
- [[sisyphus-lint]] shows the new message. The lint tests check that a cycle is reported once, and
  the order of a cycle of three issues.

| Repo | `lint` before | `lint` after |
|---|---|---|
| A chain of 3,000 dependencies | 15,845 ms | 151 ms |
| 20,000 generated issues | 2,291 ms (0.0.58) | 1,949 ms |
