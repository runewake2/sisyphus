## Summary

Let a sisyphus issue pin itself to a remote reference, such as a GitHub issue or a Jira ticket.

## Changes

- Issues can hold a `remote` URL in their frontmatter.
- `sisyphus new --remote <url>` sets it at creation.
- `sisyphus remote <name> <url>` sets it afterward; `sisyphus remote <name> --clear` removes it.
  Both mirror `sisyphus parent`.
- The URL is validated loosely: it must have a scheme and a host, nothing more.
