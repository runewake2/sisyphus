# 0.0.67

- Date: 2026-10-11
- Bookmark: samw/ai/perf-fixes
- Components: cli

## Summary

`sisyphus lint` reads each issue file once instead of twice.

## Changes

- `lint` loads every issue in full once. The issue checks use its frontmatter, and the link check
  uses its lines (`document.lines`) instead of reading the file again with `os.ReadFile`. Other
  Markdown files, and issue files that cannot be read, are read as before.
- `linkChecker.rowsOf` checks lines that the caller already has; `rows` reads a file and calls it.
  The file reads of the link check now count in the read counter of the tests.
- Tests check that `lint` reads each issue file and each document once, and that a link problem in
  an issue keeps its line number, also in a file with a byte order mark and CRLF line endings.
- New issue [[lint-reads-issues-once]] below [[large-repo-performance]], closed in this version.

| 20,000 generated issues, 100 link problems | Before | After |
|---|---|---|
| `lint` | 1,247 ms | 1,051 ms |
| `lint --json` output | | the same |
