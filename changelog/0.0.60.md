# 0.0.60

- Date: 2026-10-11
- Bookmark: samw/ai/perf-fixes
- Components: cli, sisyphus-mcp

## Summary

`sisyphus graph` refuses to draw more than 200 issues, and points to `--json` or `--mermaid` for a
larger graph.

## Changes

- When a drawing would have more issues than `--max-issues` (default 200), `graph` prints nothing on
  stdout and fails with the number of issues and what to do instead. `--max-issues 0` removes the
  limit. `--json` and `--mermaid` have no limit. The check runs before any drawing.
- Before, `graph --full` in a connected repo of 5,000 issues wrote 170 MB of text (19,429 lines of up
  to 22,612 characters), and took 65 s at 20,000 issues.
- `sisyphus_graph` has a `maxIssues` argument and gives the same error, so that an agent does not get
  megabytes of drawing.
- [[sisyphus-graph]] describes the flag. Tests cover the limit, `--json`, `--mermaid`, and `0`.

| Repo of 20,000 generated issues | Before | After |
|---|---|---|
| `graph <epic> --full` (17,902 issues) | 64,763 ms, 170 MB+ | 1,323 ms, an error |
| `graph <epic>` (2,800 issues) | 1,636 ms | 557 ms, an error |
