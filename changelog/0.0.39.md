## Summary

`sisyphus list`, `search`, and `show` warn about issue files that are not valid, instead of
showing their data as if it were good.

## Changes

- New `cmd/sisyphus/validate.go`: `issueProblems` checks one issue file for frontmatter lines that
  are not `key: value` fields, values that open a quote, `[`, or `{` and do not close it, a `state`
  that does not match the directory, and an invalid `priority`, `effort`, or `resolution`.
- `list` and `search` warn on stderr for every issue in the `--state` filter that has a problem,
  before the other filters run, so that a filter cannot hide it. `show` warns for the issue that it
  prints. A file without frontmatter gets a warning too; before, `list` skipped it silently.
- stdout does not change, so `--json` stays valid.
- [[sisyphus-list]], [[sisyphus-search]], and [[sisyphus-show]] describe the warnings.
- All issues of this repo pass the check without a warning.
