# 0.0.11

- Date: 2026-10-07
- Bookmark: samw/ai/graph-view
- Components: cli

## Summary

Add `sisyphus graph` to view a large task's whole family tree in the terminal.

## Changes

- `sisyphus graph <name>` walks up to `<name>`'s root ancestor (by `parent`), then prints the whole
  tree of descendants, in the style of the Unix `tree` command: each node as `<name> [<state>]`,
  the requested issue marked, and a `(depends on: ...)` suffix on any node that has one.
- `--json` prints the same tree as nested objects.
