## Summary

`sisyphus update <name> --title "<title>"` changes the title of an issue.

## Changes

- New flag `update --title` (`-t`). It sets the `title` field and the first `#` heading of the body
  to the same text, so that the two cannot disagree. The title rules of `sisyphus new` apply: no
  empty title, and no line break or other control character.
- `sisyphus_update` has a `title` argument.
- [[sisyphus-update]] lists the flag, and [[sisyphus-edit]] points to it for the title.

## Decisions

None. Names stay permanent; only the title changes.
