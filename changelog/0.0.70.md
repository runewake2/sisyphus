## Summary

`list --state all` and `search --state all` include every state, and an invalid value gets a
suggestion of the nearest valid one.

## Changes

- `--state all` in `list` and `search` means `open,in-progress,closed`. The MCP tools describe it.
- An invalid state, priority, effort, or resolution error ends with `Did you mean '<value>'?` when
  one valid value is near: a synonym (`done` → `closed`, `start` → `in-progress`, `urgent` →
  `critical`, `cancelled` → `abandoned`), the only valid value that starts with the input (`hi` →
  `high`), or the only valid value within an edit distance of 2 (`hihg` → `high`). The command still
  fails; the suggestion is never used by itself.
- [[sisyphus-list]] and [[commands#Invalid values]] describe both. Tests cover `all` in both
  commands, six suggestions, and an input with no suggestion.
