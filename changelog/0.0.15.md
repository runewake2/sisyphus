# 0.0.15

- Date: 2026-10-07
- Components: cli, mcp

## Summary

Suggest `bug` and `feature` as built-in tags.

## Changes

- The `issues/TEMPLATE.md` that `sisyphus init` writes lists `bug` and `feature` as built-in
  tags, with the example `[bug, scheduler]`.
- The `--tags` help of `new`, `update`, `list`, and `search`, and the matching `sisyphus-mcp`
  tool arguments, name the built-in tags. They come from one list in the code (`builtinTags`).
- Tags stay free-form: the built-in tags are suggestions, not enforced, and any other tag works.
