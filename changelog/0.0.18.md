## Summary

An issue can sit in kebab-case subdirectories below its state directory. Every command finds it by
its full name or by its file name.

## Changes

- The full name of an issue is its path below `issues/<state>/`, without `.md`, for example
  `web/auth/fix-login-bug`. The file name keeps the 2-6 word rule; each directory is kebab-case.
- `sisyphus new web/auth/fix-login-bug` creates the subdirectories. `sisyphus update` keeps them
  when the state changes. The default title comes from the file name only.
- Every command accepts the full name, the end of the full name, a wikilink, a hashtag, or a path.
  A full name always gives its own issue. A shorter form that gives more than one issue is an
  error that lists the full names.
- `parent`, `depends-on`, and `deferred-from` store the full name. A bare link in old frontmatter
  still resolves while one issue has that file name.
- `--deferred-from` tries an issue name first, and treats any other value with `/` as a bookmark.
- `list`, `search`, `show`, and `graph` print full names.
- `sisyphus new` warns, and no longer fails, when another Markdown file has the same file name. It
  still fails when an issue already has the same full name.
- The embedded template, the command help, the MCP tool schemas, [[commands]], [[sisyphus-new]],
  and [[sisyphus-update]] describe full names.

## Notes

Each lookup walks the state directories again. That is fast for hundreds of issues. A repo with many
thousands of issues may need an index that one command builds once.

This version builds on 0.0.17 (bookmark `samw/ai/jj-colocated-move`), which is not on `main` yet.
