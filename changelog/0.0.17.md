## Summary

`sisyphus update` moves an issue that git does not track with a plain rename, so the first state
change of a new issue works in a colocated jj repo.

## Changes

- `saveIssue` runs `git mv` only when the repo root has `.git` and the git index has the file
  (`git ls-files --error-unmatch`). Any other move is a plain rename.
- A new test covers an issue that git does not track in a git repo.
- [[sisyphus-update]] describes the new rule.

## Decisions

None.

## Issues

- Closed [[update-moves-untracked-issue]].

## Notes

jj adds a file to the git index only when it commits the file. So in a colocated jj repo, every new
issue is untracked by git until the next commit.
