# 0.0.45

- Date: 2026-10-11
- Bookmark: samw/ai/tracker-fixes
- Components: cli, sisyphus-mcp, ci

## Summary

New command `sisyphus lint` checks every issue and every wikilink in the repo, writes nothing, and
fails when it finds a problem. CI runs it.

## Changes

- `sisyphus lint` checks each issue file (frontmatter shape and values, state against the
  directory, one state directory per name, tags without spaces, parents and dependencies that exist
  with no cycles) and each Markdown file (every wikilink is `ok`). Each problem is one line with its
  file; the exit code is 1 when there is a problem. `--json` gives the counts and the problems.
- `cmd/sisyphus/lint.go` reuses `issueProblems` from 0.0.39. `links.go` has a new `linkChecker`
  that resolves the links of many documents against one walk of the repo; `sisyphus links` uses it
  too, with no change in output.
- New MCP tool `sisyphus_lint`. It returns the JSON as a result, also when there are problems.
  `cmd/sisyphus-mcp/main.go` shares one exec helper between the normal tools and `sisyphus_lint`.
- `.github/workflows/ci.yml` runs `sisyphus lint` after the tests.
- New page [[sisyphus-lint]]. [[commands]], [[sisyphus-mcp]], the README, and the checklist in
  [[CONTRIBUTING#Checklist for every change]] list the command.
- Tests cover each kind of problem, a clean repo, the JSON output, that lint writes nothing, and the
  MCP tool.
- `sisyphus lint` on this repo: 62 issues and 148 Markdown files, no problems, in about 20 ms.
