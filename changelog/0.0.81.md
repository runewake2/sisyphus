# 0.0.81

- Date: 2026-10-11
- Bookmark: samw/ai/ux-fixes

## Summary

New page [[issue-format]] describes the issue file for users: an example, every field, the states and
the lifecycle, the body sections, the rules that sisyphus checks, and what a repo can change in its
template. `new --context` is now an error when the template has no Context section.

## Changes

- New page [[issue-format]]. [[commands]], the README, and the Frontmatter section of
  [[CONTRIBUTING]] link to it.
- `new --context` with a template that has no Context section was silently ignored. It is now an
  error that lists the sections of the template, and no issue is created. A test covers it.
  [[sisyphus-new]] says so.

## Notes

To write the page, a template without the optional fields, with a renamed section, and with a field
of its own was tried with `new`, `start`, `update`, `show`, and `lint`. A field of its own stays in
the file, but `show` and its JSON do not print it; the page says so.
