## Summary

The `SISYPHUS_OWNER` environment variable gives the owner of an issue that starts, when `--owner` is
not given. An agent harness sets it once for each agent, so that every claim has an owner.

## Changes

- `start`, `update <name> in-progress`, and `new --state in-progress` use `SISYPHUS_OWNER` when
  `--owner` is not given. It never changes the owner of an issue that is already in progress, and
  never gives an open issue an owner.
- An issue that starts with no owner gives a warning that names `--owner` and `SISYPHUS_OWNER`.
- `list --mine` and `search --mine` show only the issues whose owner is `SISYPHUS_OWNER`. Without
  the variable, `--mine` is an error.
- `sisyphus_list` and `sisyphus_search` take `mine`. The `owner` descriptions of `sisyphus_new` and
  `sisyphus_update` name the default.
- [[commands]] has a section on environment variables. [[sisyphus-start]], [[sisyphus-update]],
  [[sisyphus-new]], [[sisyphus-list]], [[sisyphus-search]], and [[sisyphus-mcp]] describe the
  variable. [[sisyphus-start]] names git next to jj.
- The tests clear `SISYPHUS_OWNER`, so the environment of the person who runs them has no effect.
