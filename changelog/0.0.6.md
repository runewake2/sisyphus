# 0.0.6

- Date: 2026-10-07
- Bookmark: samw/ai/search-command
- Components: cli

## Summary

Add `sisyphus search` to find issues by frontmatter filters and content, with results optionally
scoped to one section.

## Changes

- `sisyphus search [<query>]` matches a case-insensitive query against an issue's title and body,
  and accepts the same frontmatter filters as `sisyphus list` (`--state`, `--priority`, `--tags`,
  `--owner`, `--parent`), combined with AND.
- `--section <heading>` restricts the query (when one is given) and the returned content to one
  section of the body, matched the same way a wikilink's `#heading` is.
- Added `sectionIn` (`links.go`), built on the existing heading-matching machinery.
- Refactored `list.go` to expose `matchingIssues` and `compareByStatePriorityName`, shared by `list`
  and `search`.
