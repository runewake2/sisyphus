- Date: 2026-10-07
- Bookmark: samw/ai/list-command

## Summary

Add `sisyphus list` to list and filter the issues in `issues/`.

## Changes

- `sisyphus list` lists issues as a table or (with `--json`) JSON, sorted by state, then priority,
  then name. Without `--state`, only open and in-progress issues are shown.
- `--state` and `--priority` each accept a comma-separated list and match any of the given values;
  `--tags` matches an issue with any of the given tags; `--owner` and `--parent` match exactly.
  Different flags combine with AND.
- Generalized `writeTable` to take any header and cells, shared by `list` and `links`.
- Updated [[AGENTS]]'s check for whether another agent already has an issue to
  `sisyphus list --state in-progress`, replacing a `jj log` + grep search over bookmarks: the
  issue's own frontmatter (`state`, `bookmark`, `owner`) already has this, directly.
