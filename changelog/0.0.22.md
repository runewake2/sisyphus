## Summary

`sisyphus graph` places each issue one column after the farthest issue that points to it, so arrows
no longer turn back or run side by side.

## Changes

- An issue goes one column after the farthest issue that points to it, not after the first. The
  sub-issues of an epic that depend on each other are in successive columns.
- In each column, an issue takes the mean row of the issues in its directory that point to it.
- An issue that an arrow reaches from two or more columns back takes a row that is free in every
  column between, so the arrow is one straight line.
- [[sisyphus-graph]] has new examples and describes the placement.
