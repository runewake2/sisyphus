## Summary

`sisyphus update` and `sisyphus new` warn when an issue is in progress while some of its
`depends-on` issues are not closed.

## Changes

- `update <name> in-progress` and `new --state in-progress` warn, and name each `depends-on` issue
  that is not closed. The issue still starts. Before, there was no warning, although closing an
  issue already warned about the issues that depend on it.
- sisyphus-mcp returns the warning after the output, as it does for every warning.
- [[sisyphus-update]] and [[sisyphus-new]] list the warning.

## Decisions

None. The issue chose a warning, not an error, because a person may start blocked work on purpose.
