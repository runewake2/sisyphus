# 0.0.92

- Date: 2026-10-11
- Bookmark: samw/ai/ux-fixes
- Components: sisyphus-mcp, docs

## Summary

sisyphus-mcp gives the client instructions when it connects: how to find work, claim it, record
progress, and close it. Before, an agent saw the tools but not the order to use them in.

## Changes

- The `initialize` result has `instructions` of less than 200 words, with the workflow, the rule to
  select another issue when a start is refused, and how to give lists and `dir`.
- When the `sisyphus` binary has another version ([[0.0.91]]), a warning line follows the
  instructions, so that the agent can tell the user before a tool fails.
- Tests check the length, that every tool that the instructions name exists, and that
  [[sisyphus-mcp]] shows the instructions as they are.
