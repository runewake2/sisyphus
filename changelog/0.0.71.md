## Summary

`sisyphus new --title "Fix the login bug"` makes the name from the title, so a name is no longer
needed.

## Changes

- `new` takes the name as an optional argument. Without it, the name is made from `--title` with the
  rules of `sisyphus slug`, unique in the repo (`fix-login-bug`, then `fix-login-bug-2`). Without a
  name and a title, `new` fails and shows an example.
- A name that is not valid but is title text gets a suggestion:
  `To use it as the title, run: sisyphus new fix-login-bug --title "Fix the login bug"`.
- In `sisyphus_new`, `name` is optional in the same way.
- [[sisyphus-new]] describes both forms. Tests cover the name from a title, a taken name, the
  suggestion, a missing name and title, and the MCP tool.
