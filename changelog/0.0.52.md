  gives no issue, and with the usual error when it gives more than one. Before, a typo printed an
  empty list, the same as an epic with no sub-issues.
- The check uses the index that the command already builds, so each command still reads each state
  directory once.
- [[sisyphus-list]] states the rule. The MCP tools give the same error.
