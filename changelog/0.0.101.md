## Summary

The JSON rows of `list` and `search` have `bookmark` when it is set. Before, a model that answered
"what bookmark is this issue on?" from a row had no bookmark to read, and gave a wrong value.

## Changes

- `list --json` and `search --json` rows have `bookmark`, left out when it is empty. The MCP tools
  return it too.
- The table of `list` does not change.
- [[sisyphus-list]] and [[sisyphus-search]] list the field. A test covers it.
