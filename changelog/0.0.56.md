## Summary

When an issue in a subdirectory changes state, sisyphus removes the subdirectories that the move
leaves empty.

## Changes

- After a move, `saveIssue` removes the old directory of the issue and each directory above it that
  is now empty, up to but not including the state directory, for example `issues/open`. A directory
  that still has a file stays. Before, empty directories such as `issues/open/web/auth/` stayed and
  collected in the working copy and in Obsidian.
- [[sisyphus-update]] describes it.
- Tests cover a nested move next to another issue, and a move that leaves the state directory.
