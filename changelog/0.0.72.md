## Summary

`new`, `update`, `edit`, `parent`, `depends-on`, and `remote` have `--json`, which prints the
changed issue instead of only its path.

## Changes

- With `--json`, a command that changes an issue prints the issue as `show --json` does, plus `path`
  (the file) and `warnings` (a list). The warnings then go into the JSON, not to stderr. Without
  `--json`, the output stays the path.
- `sisyphus_new`, `sisyphus_update`, `sisyphus_edit`, `sisyphus_parent`, `sisyphus_depends_on`, and
  `sisyphus_remote` have an optional `json` argument. Without it they return the path, as before, so
  that the output stays short for small models.
- The page of each command describes the output. Tests cover every command, the warnings, and the MCP
  argument.

## Decisions

None. The MCP tools offer `json` instead of always using it, because the short path output helps
small local models ([[ollama-local-models]]).
