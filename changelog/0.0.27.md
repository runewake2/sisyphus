## Summary

In a colored `sisyphus graph`, each issue that an arrow links directly to `<name>` is bold in the
color of its state.

## Changes

- Blue for open, yellow for in-progress, green for completed, and red for abandoned. A closed
  issue with no resolution is completed.
- A legend line, only with color, names each state color that the drawing uses.
- `--json` nodes have `resolution` for a closed issue that has one.
- [[sisyphus-graph]] lists the state colors.
