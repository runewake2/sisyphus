# Narrow sisyphus init to set up issues/ only

## Summary

`sisyphus init` wrote a whole project-scaffolding kit (`AGENTS.md`, `CONTRIBUTING.md`,
`CHANGELOG.md`, `VERSION`, `design/decisions/`, and two `.github/workflows/*.yml`). That is scope
creep: sisyphus is an issue manager. `init` should set up `issues/` and nothing else; the rest is a
different, separate project template's job.

## Context

Removed everything from `cmd/sisyphus/kit/` except `issues/TEMPLATE.md.tmpl` and the
`issues/{open,in-progress,closed}/.gitkeep.tmpl` files. `initRepo` (`init.go`) no longer templates
anything (no `{%...%}` substitutions remain in what it writes), so `kitValues` and `init`'s
`--project`/`--bookmark-prefix` flags were dropped along with it.

This repo's own `AGENTS.md`/`CONTRIBUTING.md`/`CHANGELOG.md`/`VERSION`/`design/decisions/`/
`.github/workflows/*.yml` stay: sisyphus-the-project still wants them for its own development, they
are just no longer generated by `sisyphus init`, and `CONTRIBUTING.md` now says so.

Supersedes [[init-force-resets-version]]: since `init` no longer touches `VERSION` or
`CHANGELOG.md` at all, the bug it described can no longer happen.

## Acceptance criteria

- [x] `sisyphus init` writes only `issues/TEMPLATE.md` and the three state directories.
- [x] The removed kit files' flags (`--project`, `--bookmark-prefix`) are gone from `init --help`.
- [x] `README.md` and `CONTRIBUTING.md` describe the new, narrower scope.
- [x] Existing tests updated; `init_test.go` no longer expects the removed files.

## Out of scope

- Deleting this repo's own already-materialized `AGENTS.md`/`CONTRIBUTING.md`/etc.; they are kept,
  just no longer sourced from `sisyphus init`.
- Building the separate project-scaffolding template itself.

## Notes

- 2026-10-07: Implemented as planned. Also closing [[init-force-resets-version]] as superseded by
  this change rather than fixed directly, since its premise (`init --force` touching `VERSION`/
  `CHANGELOG.md`) no longer applies.

## Resolution

Completed: `sisyphus init` now only sets up `issues/`. See [[0.0.10]].
